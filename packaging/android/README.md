# Win Computer — Android WebView thin client (source only)

This directory is a real Android Studio/Gradle source project for the online Win Computer web app. It is a thin WebView client, not a standalone Android business application. The central HTTPS web app and its central database remain the only business source of truth.

## Scope and runtime behavior

- Internet access and an available public HTTPS server are required. There is no offline mode, local business database, LAN-only mode, automatic local sync, or standalone fallback UI.
- Configure exactly one value in `app/build.gradle`: `buildConfigField 'String', 'WEB_APP_ORIGIN', '"https://app.example.com"'`.
- The origin must be HTTPS, include a host, and contain no credentials, query, fragment, or non-root path. Use a valid publicly trusted TLS certificate; do not use HTTP or a cleartext/self-signed deployment in production.
- Top-level navigation is limited to the configured HTTPS scheme, host, and port. Arbitrary external navigation and new windows are not opened.
- Cleartext traffic, file URLs, content URLs, mixed content, and third-party cookies are disabled. JavaScript and DOM storage are enabled because the hosted web app requires them.
- Android WebView's normal app profile persists cookies and cache for login/session continuity. This wrapper does not create or maintain a business-data database or local JSON store.
- `res/drawable/win_logo.png` reuses the supplied project logo as the app icon.

## Build in Android Studio

1. Open `packaging/android` as an existing project in Android Studio.
2. Install an Android SDK platform for API 35 and a compatible Android SDK Build-Tools package when Android Studio prompts you.
3. Edit `app/build.gradle` and replace the example `WEB_APP_ORIGIN` with the exact public HTTPS origin.
4. Let Android Studio sync Gradle, then use **Build > Make Project** or **Build > Generate App Bundles or APKs**.

## Build from a shell

From `packaging/android` on a machine with Java 17+ and the Android SDK configured:

```bash
gradle :app:assembleDebug
# Optional release bundle (configure signing in a private build environment first):
gradle :app:bundleRelease
```

Use `--offline` only when the Android Gradle Plugin and all dependencies are already cached locally.

If a Gradle wrapper is generated by Android Studio, the equivalent reproducible commands are `./gradlew :app:assembleDebug` and `./gradlew :app:bundleRelease`. This repository intentionally does not check in a fabricated APK or signing keys.

## Current environment limitation

This environment has Java but no Android SDK, `adb`, or Gradle executable, so the Android project is source-only here and was not compiled or device-tested. Do not interpret these Java/XML/Gradle files as an APK. Build and test on a machine with Android Studio/SDK and a real HTTPS deployment.
